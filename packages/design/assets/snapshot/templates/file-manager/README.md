# Skill Studio

Branded file-manager / studio app shell: sidebar file tree, tabbed editor panels, toolbar,
reference cards and a chat composer. The densest template here — a working app surface rather
than a marketing page.

[`index.html`](index.html) is the shell, [`studio.js`](studio.js) the behaviour,
[`app-data.js`](app-data.js) the seed content.

## Density is allowed here

Corporate and marketing surfaces stay roomy; product surfaces like this one may tighten.
Compact controls (`--control-h-sm`, 34px) are acceptable in the toolbar where a larger padded
wrapper carries the real hit target. Everything else keeps the 44px floor.

See [`../../DESIGN.md`](../../DESIGN.md) for the verified rules.
