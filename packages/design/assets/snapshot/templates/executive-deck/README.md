# Executive Deck

Editorial executive-briefing deck on [`deck-stage.js`](deck-stage.js): navy cover, key
takeaways, breakdown matrix, requirements, build outputs, benefits.

More text-dense and more structured than the [Presentation Deck](../deck) — built for a
reading audience rather than a presenting one. Reach for it when the content is an argument
with evidence, not a company overview.

## Editing

One `<section>` per slide inside `<deck-stage>`. Keep the matrix and requirements tables to
the column counts already there; they are tuned to stay above 24px at 1920×1080.

See [`../../DESIGN.md`](../../DESIGN.md) for the verified type and color rules.
