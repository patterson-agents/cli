# Purpose, Vision & Values Deck

A faithful reversal of the Patterson corporate **Purpose · Vision · Values** PowerPoint,
rebuilt on [`deck-stage.js`](deck-stage.js).

Slides: cover · icon-rail content slides · navy section dividers · four-colour values columns ·
funnel · statement lockups · word-cloud closer.

This is the closest thing here to an official corporate artifact — the structure mirrors the
source deck rather than being freely designed. Keep that correspondence if you edit it; if you
need a freer structure, start from the [Presentation Deck](../deck) instead.

The four-colour values columns are the one sanctioned use of the tertiary palette
(green / teal / purple) outside charts. See [`../../DESIGN.md`](../../DESIGN.md).
