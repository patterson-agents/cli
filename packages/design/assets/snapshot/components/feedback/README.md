# Feedback components

Specimen card: [`feedback.card.html`](feedback.card.html).

| Component | Notes |
| --- | --- |
| [`Alert`](Alert.jsx) | Four tones — info (blue), success (teal), warning (amber), danger (red) — on their matching `-bg` tint with a 1px border, a line icon and 14px body. Semantics are drawn from the tertiary palette so alerts never look foreign on a Patterson page. |
| [`Tabs`](Tabs.jsx) | Inactive: transparent with body-gray text. Active: navy text with a **3px sky bottom border**. Never a filled pill tab. |

See [`../../DESIGN.md`](../../DESIGN.md).
