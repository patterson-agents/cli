# Deck imagery

Backgrounds, spot illustrations and lockups extracted from the official Patterson corporate
PowerPoint decks. Consumed by [`templates/deck`](../../../templates/deck),
[`templates/executive-deck`](../../../templates/executive-deck) and
[`templates/purpose-vision-values`](../../../templates/purpose-vision-values).

| File | Use |
| --- | --- |
| `bg-cover-panel.png` | Cover-slide panel treatment |
| `bg-navy-plain.png` | Flat navy slide ground |
| `bg-wave-navy.png` / `bg-wave-light.png` | The wave watermark on navy / on light |
| `bg-bluebar.png` | Blue bar divider band |
| `icon-binoculars.png` · `icon-handshake.png` · `icon-people.png` | Two-tone navy+sky spot illustrations (Vision / Partnership / People) |
| `lockup-we-are-patterson.png` | "We Are Patterson" lockup |
| `funnel-pvv.png` | Purpose·Vision·Values funnel diagram |
| `wordcloud-navy.png` | Values word-cloud closer |

The spot icons are **navy-and-sky two-tone line illustrations** with heavy rounded strokes —
a separate tier from the [icon font](../../fonts), which covers small single-color UI glyphs.
See [`../../../DESIGN.md`](../../../DESIGN.md).
