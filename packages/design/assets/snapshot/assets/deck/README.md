# Deck styling

Shared slide styling for the deck templates.

- [`patterson-slides.css`](patterson-slides.css) — slide-level type scale, band layouts and
  helper classes built on the brand tokens.
- [`slide-layouts.html`](slide-layouts.html) — a visual index of the available slide
  archetypes. Open it to pick a layout before building a deck.

Used by [`templates/deck`](../../templates/deck),
[`templates/executive-deck`](../../templates/executive-deck) and
[`templates/purpose-vision-values`](../../templates/purpose-vision-values).

Slide text never drops below **24px** at 1920×1080 — see [`../../DESIGN.md`](../../DESIGN.md).
